# Third-party components

The runtime installs Python dependencies from `requirements.txt`; keep their package licenses with any redistributed build. The BRD lists these model/framework references for this prototype:

- Qwen2.5-0.5B-Instruct local language model: https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct
- all-MiniLM-L6-v2 sentence embedding model: https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2
- LangGraph Python orchestration: https://github.com/langchain-ai/langgraph

Model weights download on first use and are not bundled in this source release. Recheck model and package license terms before redistribution. Apple Support documents are fetched into the private local index on demand; source URLs and revisions are retained with each passage. Do not redistribute an indexed document corpus as part of the app.
